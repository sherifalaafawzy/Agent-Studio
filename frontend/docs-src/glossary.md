**A2A** (agent to agent). An open way for agents on different servers to talk. See [API and A2A](doc:api-and-a2a).

**ACP** (Agent Client Protocol). How Agent Studio drives outside coding agents. See [External agents](doc:external-agents).

**Agent.** A model with instructions, tools and a job. See [Agents](doc:agents).

**AG-UI.** How an agent shows rich answers and streams its work. See [Rich answers](doc:rich-answers).

**AI-BOM.** A bill of materials for an AI system, in CycloneDX format. See [AI-BOM](doc:ai-bom).

**Artifact.** A file or result an agent produced. See [Artifacts](doc:artifacts).

**Auto mode.** Picking a model for each message automatically. See [Chat](doc:chat).

**Barge-in.** Talking over the assistant to interrupt it. See [Live mode](doc:live-mode).

**Canvas.** A document, code or table you edit with an agent. See [Canvas](doc:canvas).

**Context window.** How much text a model can keep in mind at once, counted in tokens (about three-quarters of a word each).

**d1.** A small decision model on this PC that answers quick "which one?" or "yes or no?" questions for free.

**Embedding.** Turning text into numbers so it can be searched by meaning. See [Knowledge](doc:knowledge).

**Guardrail.** A check on what goes into a model, comes out, or what tools do. See [Guardrails](doc:guardrails).

**MCP** (Model Context Protocol). The add-on standard for giving agents tools. See [MCP servers](doc:mcp-servers).

**Ollama.** Free software that runs AI models on your own PC.

**OCSF.** A standard format for security events. See [Telemetry](doc:telemetry).

**OTLP / OpenTelemetry.** A standard format for traces. See [Telemetry](doc:telemetry).

**Provider.** The company or program a model comes from. See [Model providers](doc:providers).

**RAG** (retrieval augmented generation). Looking things up in your documents before answering. See [Knowledge](doc:knowledge).

**Sandbox.** A locked Docker box where commands run.

**Skill.** A saved how-to guide an agent reads when needed. See [Skills](doc:skills).

**SPIFFE.** A naming scheme for workload identity, used for agent IDs. See [Guardrails and identity](doc:guardrails).

**Spend limit.** The most a provider may cost you, checked before every request. See [Billing and limits](doc:billing-and-limits).

**Sub-agent.** An agent another agent hands work to. See [Agents](doc:agents).

**Token.** A small piece of text a model reads or writes. Also, a secret that grants access; never paste one into a chat.

**Workflow.** Boxes and arrows that run steps in order. See [Workflows](doc:workflows).

**Workspace.** The one folder agents may read and change.
