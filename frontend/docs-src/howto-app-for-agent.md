**You will need:** an agent, and a model for the builder. Open Agent Studio in a normal browser such as Chrome if the preview shows blank.

## Steps

1. Open **Apps** and press **New app**. Choose **Simple**.
2. Describe the app in plain words, for example "a page where staff type a question and see the agent's answer". Attach a sample file if it helps.
3. Pick the agent the app should use.
4. Press **Create and open**. The builder writes a plan first, then builds. Watch the steps tick.
5. In the preview, try it. If something is wrong, press **Pick an element**, click it, and say what to change.
6. Open the **Design** tab to change theme, font and corners, or add a ready-made part.
7. Open the **Connect** tab to add another agent or a data source. Turning on an agent's API access is a separate click that is always yours.
8. Use **undo** or compare versions if a change was not what you wanted.
9. When happy, **export** a zip, or start a git repository and push after the confirmation.

> If an error appears in the preview the builder reads it and tries to fix it, at most three times, then tells you.
