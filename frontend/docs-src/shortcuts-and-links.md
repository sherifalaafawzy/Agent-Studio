## Keyboard

| Keys | Where | What |
|---|---|---|
| **Ctrl+K** | Anywhere | Jump to a page or recent chat, or start a new chat |
| **Ctrl+/** | Anywhere | Open or close the documentation panel |
| **?** | Anywhere without a text box focused | Open the documentation panel |
| **Enter / Shift+Enter** | Message box | Send / new line |
| **/** | Workflow editor | Add a box |
| **Shift+click** | Workflow canvas | Select several boxes |
| **Delete / Backspace** | Workflow canvas | Delete the selection (the start box cannot be deleted) |
| **Arrow keys** | MCP list, canvas divider | Move, or resize |

## Addresses

| Address | Opens |
|---|---|
| `/?s=<chat id>` | A saved chat |
| `/?new=1` | A new chat |
| `/?canvas=latest` or `/?canvas=<id>` | A canvas beside the chat |
| `/agents/?agent=<id>#ag-live` | An agent, at its Live section |
| `/mcp/?server=<id>` | One MCP server |
| `/security/?agent=<id>` | An agent's scorecard |
| `/workflows/?tab=runs&run=<id>` | One workflow run |
| `/settings/#providers` | A Settings tab |
| `/docs/<page>/#<heading>` | A documentation page at a heading |

Agent section anchors in the editor: `ag-tools`, `ag-mcp`, `ag-rag`, `ag-memory`, `ag-spawn`, `ag-acp`, `ag-access`, `ag-agui`, `ag-live`, `ag-data`, `ag-runtime`, `ag-guardrails`, `ag-identity`.
