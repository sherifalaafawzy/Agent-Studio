A **skill** is a saved how-to guide, like "how to review code" or "how to write a good test". An agent reads it when it needs it, so it learns a method without becoming permanently longer or more expensive.

![The skills list](shot:skills)

## Where skills come from

- **Built in:** starter skills such as skill-creator, repo-orientation, code-review, debugging, test-writing, git-workflow, research-and-summarize and plan-and-delegate.
- **Catalog:** 24 ready-made domain skills (accounting, sales, marketing, manufacturing, engineering, data, machine learning, deep learning). See [Catalog](doc:catalog).
- **Science:** seven `science-*` skills. See [Science Lab](doc:science-lab).
- **Yours:** write one, import one, or let an agent write one with its skill-creation tool.

## Write a skill

1. Press **New skill**.
2. Give it a name and a short description, which is how an agent decides when to use it.
3. In the editor, use **Write** to type and **Preview** to see it. Describe when to use it, the steps, and what to avoid.
4. Save.

Press **Import** to bring a skill in from a file.

## Give skills to an agent

In the [agent editor](doc:agent-editor#skills) tick individual skills or a whole **group**. Ticking a group includes skills added to it later.

> **Tip:** a good skill has a clear "When to use" and a "Safety" paragraph. Domain skills in the catalog both have one.
