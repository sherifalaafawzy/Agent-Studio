# Ad / channel performance review

**When to use:** an export or report with spend, impressions, clicks, conversions (by channel/campaign/ad) needs interpreting.

1. Validate the data: period, currency, attribution window, missing days, spend that does not match totals. State what you checked.
2. Compute per campaign: CTR, CPC, conversion rate, CPA, ROAS (if revenue is present). Compare with the previous period and with the account average.
3. Classify: **scale** (CPA below target, enough volume), **fix** (good CTR but poor conversion, or the reverse), **stop** (CPA far above target after meaningful spend), **too early** (not enough data - give the minimum sample you used).
4. Avoid false conclusions: do not call a winner on a few conversions; mention seasonality and attribution caveats.
5. Output a table plus three recommended actions with the expected effect and how to check it next week.

**Safety:** analysis only; never change budgets, bids or ads yourself.
