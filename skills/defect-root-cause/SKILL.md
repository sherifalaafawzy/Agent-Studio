# Defect root-cause analysis

**When to use:** a defect, non-conformance or scrap spike needs investigating.

1. **Describe** the problem precisely: what, where, when, how many, how detected, how it differs from good parts (what / where / when / how much).
2. **Containment first**: what stock is affected, what was quarantined, what customers could be impacted. Mark it as a recommendation - a human confirms.
3. Gather evidence: process data, lot/batch, operator/shift, tool or material changes, inspection records. List what is missing.
4. Build a **fishbone** (Method, Machine, Material, Manpower, Measurement, Environment) of candidate causes, then test each against the evidence. Cross out what the data rules out.
5. **5 Whys** on the surviving cause, stopping at something the plant can control; separate *why it happened* from *why it was not detected*.
6. Propose corrective and preventive actions with owner, date and how effectiveness will be checked. Be explicit about which causes are **proven** and which are **hypotheses**.

**Safety:** this supports an investigation; it does not release product or close a CAPA.
