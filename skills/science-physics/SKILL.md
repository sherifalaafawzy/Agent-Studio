# Science: physics

**When to use:** a calculation with units or constants, or a literature search in physics and astronomy.

1. Constants: `science_calc` kind constant (CODATA 2022, with uncertainty where it is not exact). Never type a constant from memory when the tool has it.
2. Conversions: kind convert, which refuses to convert between different kinds of quantity.
3. Numerics: integrate, derivative, root, or table (to chart a function). State the method and its limits; these are floating-point results.
4. Bigger simulations: `science_run_python` in the sandbox with a seed, and keep the run record.
5. Literature: arxiv, inspire, ads (needs a free token).

**Safety:** none beyond the general rules; say when a result is a model of reality and not a measurement.
