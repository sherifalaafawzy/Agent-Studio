# SEO content audit

**When to use:** a URL (or set of URLs) should rank better or be reviewed.

1. Fetch the page (read-only). Record: title, meta description, H1-H3 outline, word count, internal/external links, images without alt text, canonical, indexability.
2. Judge **search intent**: what would a searcher expect for the target query, and does the page answer it in the first screen? Compare with 3-5 top-ranking pages for the query (cite them).
3. List issues by impact: intent mismatch, thin or duplicated content, missing keywords in title/H1, heading structure, slow or heavy page, broken links, missing structured data.
4. Output a prioritised table (issue, evidence, fix, effort) and a rewritten title + meta description suggestion.
5. Do not promise rankings. Say what was verified (page content) and what was not (real traffic, backlinks) unless analytics data was provided.

**Safety:** read-only; never change the live site.
